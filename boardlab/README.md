# BoardLab UX Prototype

This folder is ready to publish with GitHub Pages.

## What this is

BoardLab is a Milanote-inspired usability-test prototype for a tech communications class. It is configured for the college group project test scenario and includes Microsoft Clarity tracking with project ID `xvbvoql4vu`.

## Publish On GitHub Pages

1. Create a GitHub repository, for example `boardlab-ux-prototype`.
2. Put every file and folder from this directory in the root of that repository.
3. Commit the files to the `main` branch.
4. In GitHub, open `Settings` > `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Choose branch `main` and folder `/root`, then save.
7. Wait for GitHub to finish publishing.

Your public test URL will look like:

```text
https://YOUR-GITHUB-USERNAME.github.io/boardlab-ux-prototype/
```

Use that GitHub Pages URL as the website URL in Microsoft Clarity.

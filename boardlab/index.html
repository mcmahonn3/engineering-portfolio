This is not a test of you or your technical ability. We are testing whether the interface communicates clearly.

Please think out loud as you use the site: what you are looking for, what seems clear, and what feels confusing.

  1. Create and organize a project board. Imagine you are using this tool for a college group project. Create or organize three sections: Research, Drafting, and Presentation. Add at least three notes, cards, or pieces of project information and arrange them in a way that makes sense to you.
  2. Add task and collaboration elements. Add two task items related to the project. Then try to add any available deadline, label, comment, teammate note, or collaboration-related feature.
After-task questions
  1. What was easiest to understand?
  2. What was most confusing?
  3. Did the visual board help you organize the project?
  4. Did the site feel more useful for brainstorming, task tracking, or both?
  5. Were there any buttons, labels, or features that were unclear?
  6. Would you use a tool like this for a class group project? Why or why not?
  7. Rate your overall satisfaction from 1-5.
